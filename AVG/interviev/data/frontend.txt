Вопросы по фронтенду

Вопрос 1. Что такое DOM? Какая у него структура, идентификаторы элементов?
Ответ
DOM (Document Object Model) — это программный интерфейс, представляющий HTML или XML документ в виде дерева объектов, с которыми можно взаимодействовать через JavaScript.
Структура:

Узлы (Nodes): DOM представляет документ как дерево, где каждый элемент, атрибут, текст или комментарий — это узел.

Элементные узлы: HTML-теги (<div>, <p>).
Текстовые узлы: Текст внутри тегов.
Атрибуты: Атрибуты тегов (например, id, class).
Корневой узел: <html> или объект document.


Иерархия: Дерево начинается с document, далее идут <html>, <head>, <body>, и так далее.

Идентификаторы элементов:

id: Уникальный идентификатор элемента (например, <div id="myDiv">).

Доступ: document.getElementById('myDiv').


class: Классы для стилизации или группировки (например, <div class="myClass">).

Доступ: document.getElementsByClassName('myClass') или document.querySelector('.myClass').


name: Используется в формах (например, <input name="username">).

Доступ: document.getElementsByName('username').


Теги: Поиск по типу тега (например, document.getElementsByTagName('div')).
CSS-селекторы: Используются с querySelector/querySelectorAll (например, document.querySelector('#myDiv .myClass')).

Вопрос 2. JavaScript, опыт работы с ним, используемые библиотеки?
Ответ
JavaScript — это динамический язык программирования для создания интерактивных веб-приложений. Опыт работы зависит от контекста, но типичные задачи включают:

Манипуляции с DOM (добавление/удаление элементов, обработка событий).
Асинхронное программирование (AJAX, Fetch API, async/await).
Работа с API (REST, GraphQL).
Создание SPA (Single Page Applications).

Популярные библиотеки и фреймворки:

React: Для построения компонентных интерфейсов.
Vue.js: Лёгкий фреймворк для реактивных приложений.
Angular: Полноценный фреймворк для сложных приложений.
jQuery: Для упрощения работы с DOM (хотя сейчас реже используется).
Lodash: Утилиты для работы с массивами, объектами.
Axios: Для HTTP-запросов.
D3.js: Для визуализации данных.
Node.js: Для серверной разработки на JavaScript.

Вопрос 3. Какие существуют типы данных в JavaScript?
Ответ
JavaScript имеет примитивные и ссылочные типы данных.
Примитивные типы:

undefined: Переменная не определена.
null: Отсутствие значения.
boolean: true или false.
number: Числа (например, 42, 3.14).
bigint: Для целых чисел произвольной длины.
string: Строки (например, "hello").
symbol: Уникальные идентификаторы (введены в ES6).

Ссылочные типы:

object: Объекты, включая массивы ([]), функции, даты (Date), и т.д.
Специальные объекты: Array, Function, Map, Set, RegExp, и т.д.

Вопрос 4. Что такое функция в JavaScript?
Ответ
Функция — это блок кода, предназначенный для выполнения определённой задачи, который можно вызывать многократно. Функции в JavaScript являются объектами первого класса, то есть их можно передавать, присваивать переменным и возвращать из других функций.
Синтаксис:
javascript// Объявление функции
function myFunction(a, b) {
return a + b;
}

// Функциональное выражение
const myFunc = function(a, b) {
return a + b;
};
Особенности:

Могут быть именованными или анонимными.
Поддерживают замыкания и аргументы по умолчанию.
Могут быть вызваны как методы объектов или конструкторы.

Вопрос 5. Что такое стрелочная функция (arrow function) в JavaScript?
Ответ
Стрелочная функция — это компактный синтаксис для объявления функций, введённый в ES6.
Синтаксис:
javascriptconst add = (a, b) => a + b;
Особенности:

Краткость: Упрощённый синтаксис, особенно для однострочных функций.
Отсутствие собственного this: Стрелочные функции наследуют this из внешнего контекста (лексическое связывание).
Не могут быть конструкторами: Нельзя использовать с new.
Отсутствие arguments: Нет собственного объекта arguments.

Пример:
javascriptconst obj = {
value: 42,
regular: function() { console.log(this.value); }, // 42
arrow: () => { console.log(this.value); } // undefined (this из внешнего контекста)
};

Вопрос 6. Области видимости переменных и функций?
Ответ
Область видимости определяет, где переменные и функции доступны в коде.
Типы областей видимости:

Глобальная область:

Переменные, объявленные вне функций, доступны повсюду.
Пример: var globalVar = 10;.


Локальная (функциональная) область:

Переменные, объявленные внутри функции, доступны только внутри неё.
Пример:
javascriptfunction myFunc() {
var localVar = 20; // Доступно только в myFunc
}



Блочная область (ES6):

Переменные, объявленные с let или const, ограничены блоком {}.
Пример:
javascriptif (true) {
let blockVar = 30; // Доступно только в блоке if
}
console.log(blockVar); // Ошибка




Замыкания:

Функция сохраняет доступ к переменным из внешней области видимости, даже после завершения внешней функции.
Пример:
javascriptfunction outer() {
let x = 10;
return function inner() {
console.log(x); // 10
};
}
const fn = outer();
fn();


Различия var, let, const:

var: Функциональная или глобальная область, подвержена "всплытию" (hoisting).
let: Блочная область, не всплывает.
const: Блочная область, не допускает переприсваивания (но объект/массив можно изменять).

Вопрос 7. Как реализовано ООП в JavaScript?
Ответ
JavaScript использует прототипное ООП, в отличие от классического (на основе классов). С ES6 добавлен синтаксис классов, упрощающий реализацию.
Ключевые концепции:

Объекты: Основная единица, содержащая свойства и методы.
Прототипы:

Каждый объект имеет прототип, от которого наследует свойства и методы.
Пример: Object.prototype, Array.prototype.


Конструкторы:

Функции для создания объектов.
Пример:
javascriptfunction Person(name) {
this.name = name;
}
Person.prototype.sayHello = function() {
return `Hello, ${this.name}`;
};



Классы (ES6):

Синтаксический сахар для прототипного наследования.
Пример:
javascriptclass Person {
constructor(name) {
this.name = name;
}
sayHello() {
return `Hello, ${this.name}`;
}
}



Наследование:

Реализуется через цепочку прототипов или extends в классах.
Пример:
javascriptclass Student extends Person {
constructor(name, grade) {
super(name);
this.grade = grade;
}
}




Особенности:

Динамическая природа: свойства и методы можно добавлять/удалять в любой момент.
Нет строгих интерфейсов или абстрактных классов.

Вопрос 8. Что означает ключевое слово `this` для функции и объекта?
Ответ
this — это контекст выполнения функции, который зависит от того, как функция вызвана.
В функциях:

Обычная функция:

this зависит от способа вызова:

Глобальный контекст: window (в браузере) или global (в Node.js).
Как метод объекта: this — это объект, владеющий методом.
Через new: this — новый созданный объект.


Пример:
javascriptfunction myFunc() {
console.log(this);
}
myFunc(); // window (в браузере)
const obj = { myFunc };
obj.myFunc(); // obj



Стрелочная функция:

this берётся из внешнего лексического контекста (не зависит от вызова).
Пример:
javascriptconst obj = {
arrow: () => console.log(this), // window (внешний контекст)
regular: function() { console.log(this); } // obj
};




В объектах:

this указывает на объект, в котором вызывается метод.
Пример:
javascriptconst person = {
name: 'John',
sayName() {
return this.name;
}
};
console.log(person.sayName()); // John

Вопрос 9. Какие отличия между методами `call` и `apply`?
Ответ
Оба метода вызывают функцию, задавая её контекст (this) и передавая аргументы, но отличаются способом передачи аргументов.
call:

Передаёт аргументы по отдельности через запятую.
Синтаксис: function.call(thisArg, arg1, arg2, ...).
Пример:
javascriptfunction greet(greeting) {
console.log(`${greeting}, ${this.name}`);
}
const person = { name: 'John' };
greet.call(person, 'Hello'); // Hello, John


apply:

Передаёт аргументы в виде массива.
Синтаксис: function.apply(thisArg, [arg1, arg2, ...]).
Пример:
javascriptgreet.apply(person, ['Hello']); // Hello, John


Ключевая разница:

call: Аргументы передаются как список (arg1, arg2, ...).
apply: Аргументы передаются как массив ([arg1, arg2, ...]).
Производительность: call может быть быстрее для небольшого числа аргументов.

Современный контекст:

В ES6+ часто используется ... (spread) вместо apply:
javascriptgreet.call(person, ...['Hello']); // Аналог apply

Вопрос 19. Что такое события? Методы `bind` / `unbind`.
Ответ
События:

События — это действия пользователя или системы (например, клик, нажатие клавиши, загрузка страницы), которые можно отслеживать и обрабатывать с помощью JavaScript.
Пример: Событие click на кнопке.
javascriptdocument.querySelector('button').addEventListener('click', () => alert('Clicked!'));


Метод bind:

Не путать с привязкой событий! Function.prototype.bind создаёт новую функцию с фиксированным контекстом this и/или аргументами.
Пример:
javascriptconst person = { name: 'John' };
function greet() {
console.log(this.name);
}
const boundGreet = greet.bind(person);
boundGreet(); // John

Используется для сохранения контекста, например, в обработчиках событий.

Методы bind / unbind (в контексте событий):

В современном JavaScript нет методов bind/unbind для событий. Эти термины использовались в старых библиотеках, например, jQuery:

bind: Привязка обработчика события (аналог addEventListener).
unbind: Удаление обработчика (аналог removeEventListener).


В нативном JavaScript:

Привязка: element.addEventListener('click', handler).
Отвязка: element.removeEventListener('click', handler).
Пример:
javascriptfunction handler() { console.log('Clicked'); }
const btn = document.querySelector('button');
btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);

Вопрос 11. Как происходит всплытие события в DOM? Как предотвратить всплытие события?
Ответ
Всплытие события (Event Bubbling):

Когда событие (например, click) происходит на элементе, оно сначала обрабатывается на самом элементе, затем "всплывает" вверх по дереву DOM, вызывая обработчики на родительских элементах.
Пример:
javascript<div onclick="alert('Div')">
<button onclick="alert('Button')">Click me</button>
</div>
// Клик по кнопке вызовет сначала alert('Button'), затем alert('Div').


Захват события (Event Capturing):

Менее распространённый режим, где событие сначала обрабатывается на самом верхнем элементе (например, document), затем спускается вниз.
Включается через addEventListener(event, handler, { capture: true }).

Предотвращение всплытия:

Используйте метод event.stopPropagation():
javascriptdocument.querySelector('button').addEventListener('click', (event) => {
event.stopPropagation(); // Останавливает всплытие
console.log('Button clicked');
});

Осторожно: event.stopImmediatePropagation() также предотвращает выполнение других обработчиков на том же элементе.

Примечание:

Для полной остановки стандартного поведения браузера (например, переход по ссылке) используйте event.preventDefault().

Вопрос 12. Что такое колбеки?
Ответ
Колбек (callback) — это функция, переданная в качестве аргумента другой функции, которая будет вызвана после завершения определённой операции.
Пример:
javascriptfunction fetchData(callback) {
setTimeout(() => {
callback('Data loaded');
}, 1000);
}
fetchData((data) => console.log(data)); // Data loaded
Особенности:

Используются для асинхронного программирования (например, обработка событий, AJAX).
Проблема: "Callback hell" при вложенных вызовах.
Альтернативы: Promises, async/await.
javascript// Современный подход с Promise
async function fetchData() {
return new Promise((resolve) => setTimeout(() => resolve('Data loaded'), 1000));
}
(async () => {
const data = await fetchData();
console.log(data); // Data loaded
})();

Вопрос 13. В чем отличие операторов `==` и `===` в JavaScript?
Ответ
== (нестрогое сравнение):

Сравнивает значения, выполняя приведение типов (type coercion).
Пример:
javascriptconsole.log(5 == '5'); // true (строка приводится к числу)
console.log(null == undefined); // true


=== (строгое сравнение):

Сравнивает значения и типы без приведения типов.
Пример:
javascriptconsole.log(5 === '5'); // false (разные типы: number и string)
console.log(null === undefined); // false


Ключевая разница:

==: Проверяет только значение, приводя типы (например, '5' → 5).
===: Проверяет значение и тип, не выполняя приведение.
Рекомендация: Используйте === для предсказуемого поведения, так как == может привести к неожиданным результатам из-за приведения типов.

Пример:
javascriptconsole.log(0 == false); // true
console.log(0 === false); // false

Вопрос 15. Рассказать, что происходит во время AJAX-запросов и для чего они нужны


Ответ 
XHR-запрос (XMLHttpRequest) на сервер отправляется при помощи JavaScript.

Сервер с учётом данных запроса формирует ответ с JSON/XML-содержимым. В браузере часть содержимого страницы заменяется при помощи скрипта. При этом пользователь остаётся на той же странице.

Это позволяет ускорить загрузку страницы и сделать сёрфинг более комфортным для пользователя.
